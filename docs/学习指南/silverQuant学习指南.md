## 📚 第一阶段：架构理解（第1-2周）

### 1.1 核心概念认知

#### 系统架构
silverQuant采用**5层架构设计**：

1. **用户接口层**：策略入口文件（run_*.py）
2. **策略执行层**：交易策略组件（trader/、selector/）
3. **核心服务层**：业务逻辑处理
4. **数据访问层**：多数据源支持（reader/）
5. **交易执行层**：交易委托和回调（delegate/）

#### 关键设计模式
- **策略模式**：买卖策略组件化，灵活组合
- **委托模式**：交易执行与策略逻辑分离
- **工厂模式**：不同数据源的统一创建
- **观察者模式**：市场数据订阅和事件驱动

## 📚 第三阶段：策略组件开发（第4-5周）

### 3.1 买入策略组件

#### 核心配置参数
```python
class BuyConf:
    time_ranges = [['09:30', '10:30']]  # 买入时间窗口
    interval = 30                       # 扫描间隔（秒）
    order_premium = 0.02               # 市价单溢价
    slot_count = 10                    # 最大持仓数量
    slot_capacity = 10000              # 单仓位资金上限
    daily_buy_max = 10                 # 单日买入上限
    inc_limit = 1.07                   # 涨幅限制
```

### 3.2 卖出策略组件

#### 风险控制参数
```python
class SellConf:
    earn_limit = 9.999                  # 硬性止盈率
    risk_limit = 1 - 0.04              # 硬性止损率
    risk_tight = 0.002                 # 止损率每日上移
    switch_hold_days = 1               # 换仓持仓天数
    fall_from_top = 0.03               # 回撤止盈
```

### 4.1 风险控制机制

#### 多层次风险控制
1. **仓位控制**：总仓位、单仓位限制
2. **止盈止损**：硬性止盈、动态止损
3. **时间控制**：持仓时间、交易时间窗口
4. **回撤控制**：动态回撤止盈
5. **黑名单过滤**：ST股票、退市股票过滤
