# SilverQuant 系统架构设计文档

## 项目简介
SilverQuant是一个基于MiniQMT的A股全自动量化交易框架，采用分层架构设计，支持多种数据源和交易端，提供丰富的风控组件和开箱即用的策略模板。

## 架构设计原则
- **分层解耦**：数据层、策略层、交易层清晰分离
- **组件化设计**：买入、卖出、选股可独立配置
- **多数据源支持**：AKShare、Tushare、TDX、MiniQMT
- **容错机制**：多级缓存和降级策略
- **开箱即用**：提供完整的策略模板
