## 6. 运行时依赖链

```plantuml
@startuml
!theme plain
skinparam defaultFontName "Microsoft YaHei"
skinparam defaultFontSize 16
skinparam classFontSize 14
skinparam classAttributeFontSize 13
skinparam sequenceMessageFontSize 14
skinparam sequenceParticipantFontSize 14
skinparam monochrome false
skinparam shadowing false

title 运行时依赖链

participant "主程序" as Main
participant "凭证模块" as Cred
participant "交易代理" as Del
participant "数据订阅" as Sub
participant "缓存管理" as Cache
participant "策略引擎" as Strat
participant "工具模块" as Tools
participant "外部库" as Ext

== 程序启动依赖链 ==

Main -> Cred: 加载凭证
Cred -> Tools: 验证配置格式
Tools -> Ext: 使用标准库函数

Main -> Del: 创建交易代理
Del -> Tools: 使用基础工具
Del -> Ext: 导入xtquant
Del -> Cred: 获取账户信息

Main -> Sub: 创建数据订阅
Sub -> Del: 绑定交易代理
Sub -> Ext: 导入数据源库
Sub -> Cache: 初始化缓存

Main -> Strat: 初始化策略
Strat -> Tools: 使用计算工具
Strat -> Cache: 获取历史数据
Strat -> Del: 设置回调

Main -> Ext: 启动调度器
Ext --> Main: 调度器就绪

== 运行时循环依赖 ==

loop 策略执行
  Sub -> Ext: 获取实时数据
  Sub -> Cache: 更新缓存
  Sub -> Strat: 推送数据

  Strat -> Cache: 读取历史数据
  Strat -> Tools: 计算指标
  Strat -> Del: 发送交易指令

  Del -> Ext: 执行交易
  Del -> Cache: 更新交易记录
  Del -> Strat: 回调执行结果
end

@enduml
```
